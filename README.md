# Proyecto de Geolocalización con GraphHopper

Este proyecto consiste en un script en Python que utiliza la API de GraphHopper para obtener coordenadas geográficas y calcular rutas entre dos ubicaciones. El objetivo es aplicar mejoras al software de geolocalización como parte de la evaluación académica.

## Mejoras implementadas

- Interacción en español
- Redondeo de valores numéricos (distancia y duración)
- Opción para salir del programa con "s" o "salir"
- Impresión de instrucciones del viaje en español

## Requisitos

- Python 3 instalado
- Conexión a internet
- Clave API de GraphHopper (gratuita desde [graphhopper.com](https://graphhopper.com))
